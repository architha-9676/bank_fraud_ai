📖 How This System Works
1️⃣ Transaction Occurs — UPI, Credit Card, Debit Card, Net Banking, Wallet or International
2️⃣ ML Model Analyzes — XGBoost model checks transaction pattern, amount, time and location
3️⃣ Risk Score Calculated — Confidence score from 0-100% determines risk level
4️⃣ Automatic Decision — BLOCKED (90%+), FLAGGED (70-90%), MONITORING (50-70%), APPROVED (below 50%)
5️⃣ Case Created — Every suspicious transaction becomes a trackable case
6️⃣ Alert Sent — Critical cases trigger instant alerts
