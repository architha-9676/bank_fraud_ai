📖 Model Selection Process
1️⃣ Data Preparation — Loaded 284,807 transactions, applied feature scaling using StandardScaler
2️⃣ Train-Test Split — 80% training data (227,845 rows), 20% testing data (56,962 rows)
3️⃣ Model Training — Trained Random Forest, Logistic Regression, Decision Tree and XGBoost
4️⃣ Evaluation — Compared using Accuracy, Precision, Recall and F1 Score (F1 most important for imbalanced fraud data)
5️⃣ Threshold Tuning — Lowered decision threshold from 0.5 to 0.3 to catch more fraud cases (improved F1 from 84.44% to 88.04%)
6️⃣ Final Selection — XGBoost selected as production model with 99.96% accuracy and best F1 score
